# 🐍 Python — Exercícios da Aula 1

Repositório criado para guardar os exercícios que desenvolvi durante a primeira aula de **Development with Python**.

Foram realizadas **15 questões**, trabalhando principalmente a lógica de programação e os conceitos básicos da linguagem Python.

A ideia foi resolver cada problema usando somente o conteúdo apresentado durante a aula.

---

### 📚 Conteúdos utilizados

Ao longo das questões, coloquei em prática:

* Variáveis e atribuição de valores
* Entrada de dados com `input()`
* Saída de informações com `print()`
* Tipos `int`, `float`, `str`, `bool` e `None`
* Conversão de tipos
* Operações matemáticas
* Operadores de comparação
* Operadores lógicos
* Condições com `if`, `elif` e `else`
* Repetições com `for` e `while`
* `range`
* Criação de funções
* Parâmetros e argumentos
* `return`
* Escopo básico

### 💻 Como foram feitas as questões

Para cada questão, primeiro analisei o que o problema estava pedindo e quais dados seriam necessários.

Depois fui montando a solução com os recursos que já tinham sido apresentados na aula.

Dependendo do problema, utilizei contas matemáticas, condições ou repetições. Em alguns exercícios também foi necessário criar funções para organizar melhor a solução.

Depois de escrever cada código, fiz alguns testes para conferir se os resultados estavam de acordo com o que o exercício pedia.

---

### 🚧 Limitações da atividade

Como os exercícios foram feitos com base no conteúdo da primeira aula, algumas ferramentas e recursos não poderiam ser utilizados.

Por isso, não foram utilizados:

* bibliotecas e `import`;
* listas;
* tuplas;
* dicionários;
* conjuntos;
* `break` e `continue`;
* `try` e `except`;
* orientação a objetos;
* recursão;
* `match`;
* funções prontas como `min()`, `max()`, `sum()`, `sorted()`, `reversed()` e `abs()` para resolver a lógica principal.

Nos exercícios envolvendo manipulação de dígitos, também foi necessário fazer os cálculos sem transformar os números em `str`.

---

### 🧪 Testes

Os códigos foram testados com os exemplos fornecidos nos enunciados e com outros valores para verificar diferentes situações.

A intenção foi não apenas fazer o código funcionar para um único exemplo, mas tentar garantir que a lógica funcionasse também em outros casos.
